# Designer Portfolio (Next.js + TypeScript + Tailwind CSS v4)

```bash
npm install
npm run dev        # http://localhost:3000
npm run typecheck
npm run build && npm start
```

- Content (text, links, case studies, projects): `data/content.ts`
- Resume: put your PDF at `public/resume.pdf`
- Colors and the gradient background: CSS variables at the top of `app/globals.css`
  (triadic: lapis #26619C, raspberry #9C2661, moss #619C26)
- Nav active state: scroll-spy in `components/Navbar.tsx`
